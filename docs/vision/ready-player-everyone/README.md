# Ready Player Everyone

> **A work by Kenneth Courtney — forthcoming in the Angel OS Library.**

---

## About

*Ready Player Everyone* is a forthcoming work — the inversion of the lone-hero fantasy.
Not one chosen player saving the world, but **everyone** handed a controller: a vision of
abundance where the game is cooperative, the network is the prize, and the Prime Directive
of Love is the win condition.

It is being prepared for the Library alongside *Where Did Everyone Go* — same reader, same
illustrated-primer trajectory, same anonymous-first hospitality.
