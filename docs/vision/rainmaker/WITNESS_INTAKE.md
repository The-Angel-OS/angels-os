# Witness Intake — Standardized Form

**Purpose:** Capture neighbor witness statements in a consistent, court-admissible-friendly format. Each completed intake is filed as `witness_statements/[date]_[lastname].md` and the row is added to `UNIT_FORENSICS.md`.

**Approach principle:** Witnesses are not data points. They are neighbors. Approach with respect, explain the case in plain terms, request consent before any documentation begins, and offer them a copy of their own statement. **No witness is added to any filing without their explicit written consent.**

---

## The Intake Conversation — Script

**Opening (door-knock, public space, never inside their unit unless invited):**

> "Hi, I'm Ken from Unit 13 — I run the Clearwater Cruisin' channel you may have seen on YouTube. I'm documenting some issues with the way the building is being managed, specifically around the laundry situation and a few other things. Doug just sent me a 60-day notice to leave after I raised these concerns. I'm not asking you to take sides — I'm asking if you'd be willing to share what you've personally experienced as a tenant here, on your own terms. Anything you say would only be used with your written permission. Would you be open to a short conversation?"

**If yes — ask permission for each step separately:**
1. "May I record this conversation?" (audio only is fine; video is better but only if comfortable)
2. "May I take notes?"
3. "Would it be okay if I came back later with a written summary for you to review and sign?"

**If no — thank them, leave a card, walk away. They may come back later.**

## Filing Protocol

1. Complete intake → save as `witness_statements/YYMMDD_lastname.md` (private folder, not committed publicly)
2. Add the row to `UNIT_FORENSICS.md` with public-safe details only
3. If recording was made → hash the file (SHA-256), log the hash, store locally + encrypted backup
4. If witness consents to follow-up signing → return within 7 days with a clean written summary for their review and signature
5. Update the case-wide witness catalog in `v2.6_evidence_addendum.md` only with consented identification
