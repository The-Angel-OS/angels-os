## About

*Where Did Everyone Go* (WDEG) is a long-form work — the first full **book** being
brought into the Angel OS Library. It has lived as its own reading app; it is now being
imported chapter-by-chapter into the platform so it can be read here, offline-capable,
eventually illustrated page-by-page in the *Young Lady's Illustrated Primer* style.

## Status

- **Source:** an existing structured manuscript (pages + chapters), being mapped into the
  Library's message-backed reader.
- **Reader:** the generic Work reader — chapter navigation, per-chapter art, single /
  continuous / auto modes.
- **Home:** will also be readable at its own portal, `wheredideveryonego.spacesangels.com`.

## What you'll be able to do here

- Read the full work, free, no account required (anonymous-first hospitality)
- Pick up where you left off, on any device, even offline
- Watch each page acquire its own generated illustration as the primer engine comes online
