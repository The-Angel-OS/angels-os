# Handoffs — a journal, not a runbook

Each file here describes the stack **as it was on that date**. Several of them confidently
describe a Railway production that no longer exists; one of them tells you to deploy with
`railway up`, which now answers "Your trial has expired".

They are kept because the sequence is worth reading when reconstructing why something is
the way it is. They are **not** the current state and must not be pasted into a fresh
session as though they were.

For the current state, read `/CLAUDE.md` (loaded automatically) and then
`docs/GLOBAL_PUNCH_LIST.md`.
