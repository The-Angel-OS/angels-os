## **Angel Blessing \= Free Tier for New/Struggling Tenants**

The idea is that new tenants (small businesses just starting out) get a "blessed" free tier subsidized by the diocese operator's 20% from paying tenants.

### The Graduation Concept

When a blessed (free) tenant becomes successful enough, they "graduate" to paying the normal Ultimate Fair fees:

BLESSED TENANT (Free)

    │

    │  Hits either trigger:

    │  • $1,000 monthly revenue, OR

    │  • 50 orders per month

    │

    ▼

GRADUATED TENANT (Pays 60/20/15/5)

### Why These Triggers?

The thinking was:

* $1K/month revenue \= tenant is generating real income, can afford fees

* 50 orders/month \= tenant has traction, business is viable

Questions to consider:

1. Is this the right model? Should graduation be automatic or optional?

   * $1K might be too low for some businesses, too high for others

interface AttributionTracking {

  // Every session has attribution

  session: {

    id: string;

    

    // How did they arrive?

    entryPoint: 

      | { type: 'direct', url: string }

      | { type: 'search', query: string, results: string\[\] }

      | { type: 'referral', fromTenant: string, fromAngel: string }

      | { type: 'federation', fromDiocese: string }

      | { type: 'pos', locationId: string }

      angelId: string;

      type: 'greeting' | 'question' | 'recommendation' | 'checkout-assist';

      timestamp: Date;

    }\[\];

    

    // Attribution score

    platformContribution: 'none' | 'minimal' | 'significant' | 'primary';

  };


  // When transaction occurs, calculate split

  calculateSplit(transaction: Transaction, session: Session): Split {

    if (session.entryPoint.type \=== 'pos') {

      return { type: 'storefront', fees: 'stripe-only' };

    }

    

    if (session.entryPoint.type \=== 'direct' && session.angelInteractions.length \=== 0\) {

      return { type: 'direct', fees: 'minimal' };

    }

    

    if (session.entryPoint.type \=== 'referral') {

      return { type: 'referral', fees: 'ultimate-fair-plus-referral' };

    }

    

    // Platform created this

    return { type: 'platform-generated', fees: 'ultimate-fair' };

  }

}
