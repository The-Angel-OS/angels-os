##  Sprint 2 shipped — `f6544e0` on `main`

**16 files, +2,140 lines. Tests: 52 → 91 passing. Build: green.**### What actually works right now in Nimue

Open /inventory/new on any device (desktop browser, phone PWA, future native shell) and you can:**Name a batch** → pick a target Angel OS collection (Media / Products / Spaces / Dashcam / Other)
**Tag with chips** (Enter or comma to add), add notes (becomes Media alt text)
**Capture photo via device camera** (mobile triggers camera chip via capture="environment") **or pick files** (multi-select, images + video)
**Review staged grid** with per-item remove + clear-all
**Hit "Add to Queue"** → items enqueued in IndexedDB, uploader auto-starts

Then on /inventory:Live dashboard: Total / Pending / Uploading / Done / Errors tiles (uploading tile pulses)
Online/Offline banner with queued item count and pending bytes
Pause/Resume uploader button
Retry failed items, remove any item, purge all completed
Thumbnail previews rendered straight from the Blob (no server roundtrip)
Sidebar shows queue count as a live badge under the new "Field Ops" section

**The system is fully offline-tolerant.** Pull the network cable and add 50 items — they sit in IndexedDB. Reconnect and the uploader drains them at concurrency=2, with per-item exponential backoff (2s → 4s → 8s … capped 5min) on errors.### Engineering specifics worth calling out

**Dedupe is content-addressed.** SHA-256 of the blob truncated to 64 bits is the primary key. Re-add the same photo twice, same id — no duplicate upload, no duplicate row.
**Uploader uses a DOM CustomEvent bus** (nimue:uploader) so any component can react to per-item start/done/error without prop-drilling. The sidebar badge uses it. The queue hook uses it. Decoupled.
**SidebarLayout boots the uploader via dynamic import** — IndexedDB + crypto code is chunk-split out of the initial 104 kB shared bundle.
**`recoverStuck()`** runs on every uploader startup — if you closed the tab mid-upload, items pinned to uploading state get returned to pending. No zombie rows.
**Tests are real.** Not mocked queue with fake logic — actual IndexedDB (via fake-indexeddb), actual SHA-256 via webcrypto, actual backoff math validated, actual multipart FormData inspected on the upload path.
